Diccionario de datos, escenarios pensionarios y tipos de datos propuestos para modelado

NOTA SOBRE EL ALCANCE
Se transcribe la información legible de las capturas. Las fotografías muestran
fragmentos de una tabla y de un bloque de código, no los documentos completos.
No se reconstruyen ni se inventan las filas que quedaron fuera de pantalla.

======================================================================
1. DICCIONARIO DE DATOS: INFORMACIÓN DEL CLIENTE
======================================================================

Columna: id_cliente
Tipo de dato: String
Descripción: Identificador único del cliente. Incluye prefijo del régimen
(IMSS73, IMSS97, ISSSTE) y un consecutivo.

Columna: nombre
Tipo de dato: String
Descripción: Nombre(s) del cliente.

Columna: ap_paterno
Tipo de dato: String
Descripción: Apellido paterno.

Columna: ap_materno
Tipo de dato: String
Descripción: Apellido materno.

Columna: age
Tipo de dato: Integer
Descripción: Edad actual del cliente en años.

Columna: f_nacim
Tipo de dato: Date
Descripción: Fecha de nacimiento. En IMSS73 aparece generalmente en formato
YYYY-MM-DD; en IMSS97 e ISSSTE se observa formato MM/DD/YYYY.

Columna: genero
Tipo de dato: String(1)
Descripción: Género del trabajador. Valores observados: H (hombre), M (mujer).

Columna: entidad
Tipo de dato: String
Descripción: Código abreviado de la entidad federativa asociada al cliente.
Ejemplos: DF, NL, CH, BC, etc.

[Las fotografías no muestran las filas intermedias de esta tabla.]

======================================================================
2. DICCIONARIO DE DATOS: SALDOS Y AHORRO
======================================================================

Columna: saldo_ahorro_solidario
Tipo de dato: Decimal(18,2)
Descripción: Saldo acumulado por ahorro solidario (principalmente relevante
en ISSSTE). En muchos registros IMSS aparece en cero.

Columna: porcentaje_ahorro_solidario
Tipo de dato: Integer / Nullable
Descripción: Porcentaje de ahorro solidario elegido por el trabajador.
Valores observados: 1, 2 o nulo. Más relevante para ISSSTE.

Columna: saldo_bono_pension
Tipo de dato: Decimal(18,2)
Descripción: Saldo del Bono de Pensión. Aplica principalmente a trabajadores
ISSSTE en cuentas individuales.

Columna: saldo_av
Tipo de dato: Decimal(18,2)
Descripción: Saldo acumulado de aportaciones voluntarias. Puede ser cero
cuando el cliente no tiene ahorro voluntario.

Columna: saldo_vivienda
Tipo de dato: Decimal(18,2)
Descripción: Saldo disponible en subcuenta de vivienda (INFONAVIT o FOVISSSTE
según el régimen).

Columna: av_mensual
Tipo de dato: Decimal(18,2)
Descripción: Monto de aportación voluntaria mensual que realiza el cliente.
Puede ser cero si no realiza ahorro voluntario periódico.

======================================================================
3. DICCIONARIO DE DATOS: RÉGIMEN Y ESCENARIO PENSIONARIO
======================================================================

Columna: regimen_estimado
Tipo de dato: String
Descripción: Régimen pensionario identificado para el cliente
(IMSS73, IMSS97, ISSSTE).

Columna: ley_bandera
Tipo de dato: String
Descripción: Ley aplicable al cálculo pensionario. Valores observados:
LEY_73, LEY_97, LEY_ISSSTE.

Columna: escenario_estimado
Tipo de dato: String
Descripción: Resultado o escenario pensionario calculado para el cliente.
Define la ruta de beneficio esperada.
